fetch-create-website-mail.py

Holt Mails per IMAP ab und legt sie als .eml-Dateien ab

Was macht das Script?

Das Script prüft ein dediziertes IMAP-Postfach (Posteingang) und holt jede darin liegende Mail ab — es gibt keine Betreff- oder Absender-Filterung, das Script geht davon aus, dass in diesem Postfach ohnehin nur relevante Mails landen. Jede gefundene Mail wird 1:1 als .eml-Datei gespeichert und danach im Postfach in einen Archiv-Ordner verschoben.

Typischer Einsatzzweck: ein Postfach, in das gezielt Inhalte per Mail eingespielt werden (z. B. für eine spätere automatisierte Weiterverarbeitung), die das Script regelmäßig abholt und als Rohdateien bereitstellt.

Verwendung

Das Script hat keine Kommandozeilen-Parameter — Postfach, Quell-/Zielordner sind fest im Script hinterlegt (siehe Abschnitt «Dateien & Konfiguration»). Aufruf einfach ohne Argumente:

AufrufWirkung
./fetch-create-website-mail.py Holt alle Mails aus dem Quell-Ordner, speichert sie als .eml und verschiebt sie danach im Postfach ins Archiv.

Kein --dry-run vorhanden. Zum gefahrlosen Testen empfiehlt sich ein separates Test-Postfach bzw. eine Testmail in einem Postfach, dessen Verlust unproblematisch ist.

Ablauf pro Lauf

1
Per IMAP beim konfigurierten Postfach anmelden und den Quell-Ordner (INBOX) öffnen.
2
Alle vorhandenen Mails auflisten (Archiv-Ordner wird bei Bedarf automatisch angelegt, falls er noch nicht existiert).
3
Pro Mail: Rohinhalt 1:1 als .eml-Datei ablegen. Der Dateiname enthält Datum/Uhrzeit des Eingangs der Mail (nicht der Verarbeitung) — bei einer Namenskollision (zwei Mails in derselben Sekunde) wird automatisch durchnummeriert.
4
Mail im Postfach in den Archiv-Ordner verschieben — sie verschwindet damit aus dem Quell-Ordner und wird beim nächsten Lauf nicht erneut gefunden (Idempotenz).

Schlägt das Speichern oder Verschieben einer einzelnen Mail fehl, wird das im Log vermerkt und mit der nächsten Mail weitergemacht — ein Problem bei einer Mail blockiert nicht die anderen.

Häufige Fragen

Ich finde eine erwartete Mail nicht in der Ablage

Prüfen, ob sie im Postfach noch im Quell-Ordner liegt (dann ist der Lauf fehlgeschlagen, bevor er sie verarbeitet hat) oder bereits im Archiv-Ordner liegt (dann wurde sie schon abgeholt — die zugehörige Datei sollte im Zielordner liegen). Das Log des jeweiligen Laufs zeigt pro Mail, ob Speichern/Verschieben erfolgreich war.

Kann eine Mail doppelt abgeholt werden?

Nein — sobald eine Mail erfolgreich gespeichert wurde, wird sie sofort aus dem Quell-Ordner entfernt (ins Archiv verschoben). Ein erneuter Lauf sieht sie dort nicht mehr.

Dateien & Konfiguration

Postfach und Ordner sind feste Werte im Script selbst (keine externe .conf-Datei):

Script: /mnt/storage/scripts/fetch-create-website-mail.py
Credentials: /mnt/storage/credentials/mail-credentials.cred (Sektion des verwendeten Postfachs)
Zielordner (.eml-Dateien): /mnt/gdrive/Claude/emails
Quell-/Archiv-Ordner im Postfach: INBOX → archive

Aufruf: ./fetch-create-website-mail.py
