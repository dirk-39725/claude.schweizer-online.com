paperless-consolidate-tags.py

Interaktive Tag-Konsolidierung: ähnliche Tags erkennen und zusammenführen

Was macht das Script?

Geht alle Tags in Paperless-ngx durch und schlägt pro Tag bis zu 3 ähnliche Tags vor, in die er konsolidiert (zusammengeführt) werden könnte — z. B. Groß-/Kleinschreibung, Singular/Plural oder Tippfehler-Varianten. Die Ähnlichkeit wird rein per Namensvergleich geschätzt (kein ML, kein LLM-Aufruf) — die endgültige Entscheidung trifft immer der Benutzer interaktiv per Tastendruck.

Konsolidieren bedeutet: alle Dokumente, die den Quell-Tag tragen, bekommen stattdessen den Ziel-Tag zugewiesen, der Quell-Tag wird danach gelöscht.

"rechnung" → "Rechnung" (Gross-/Kleinschreibung) "Rechnungen" → "Rechnung" (Singular/Plural) "Vertraege" → "Verträge" (Tippfehler/ähnlich)

Verwendung

AufrufWirkung
./paperless-consolidate-tags.py Geht alle Tags durch (Default-Schwelle 60 % Ähnlichkeit) und fragt bei jedem gefundenen Vorschlag interaktiv nach.
./paperless-consolidate-tags.py --min-score 75 Höhere Schwelle — weniger, dafür treffsicherere Vorschläge. Kleinerer Wert liefert mehr, aber unschärfere Vorschläge.
./paperless-consolidate-tags.py --dry-run Fragt weiterhin interaktiv ab, ändert aber nichts in Paperless — zum gefahrlosen Testen des Ablaufs.

Tags aus PROTECTED_TAG_NAMES (Default: Posteingang) werden nie als Quelle eines Merges vorgeschlagen — können aber weiterhin als Ziel dienen.

Interaktive Bedienung

Bei jedem Tag mit mindestens einem Vorschlag erscheint eine nummerierte Liste:

Tag 'Rechnungen' (8 Dokumente):
  1) 'Rechnung' (42 Dokumente) - vermutlich Singular/Plural
Auswahl [1/w/z, Esc=Abbrechen]:
1 / 2 / 3In den entsprechend nummerierten Vorschlag konsolidieren (Quell-Tag wird gelöscht, Dokumente auf Ziel-Tag umgehangen).
w / WTag überspringen, weiter zum nächsten.
z / ZEinen Schritt zurück: letzte Entscheidung (Merge oder Überspringen) rückgängig machen, betroffener Tag wird erneut zur Entscheidung angezeigt. Mehrfaches z geht mehrere Schritte zurück.
Esc / Strg+CScript sofort abbrechen — bereits vorgenommene Konsolidierungen bleiben bestehen.

Vorschläge sind absteigend nach Ähnlichkeit sortiert (bei Gleichstand nach Dokumentenanzahl des Ziels). Tags ohne passenden Vorschlag werden automatisch übersprungen, ohne Nachfrage.

Rueckgängig machen (Taste "z")

Ein rückgängig gemachter Merge legt den gelöschten Quell-Tag per API neu an — er bekommt dabei zwangsläufig eine neue ID, die alte ist mit dem Löschen verloren — und hängt alle zuvor betroffenen Dokumente wieder auf ihren ursprünglichen Tag-Stand um. Ein rückgängig gemachtes Überspringen zeigt den Tag einfach erneut zur Entscheidung an.

Die Historie gilt nur für den aktuellen Lauf (In-Memory-Stack) — nach Abbruch/Ende des Scripts ist kein weiteres Rückgängigmachen mehr möglich.

Voraussetzungen

  • Benötigt ein echtes Terminal — die Tastenabfrage funktioniert nicht ohne interaktive Sitzung (Skript bricht ohne TTY mit Fehlermeldung ab).
