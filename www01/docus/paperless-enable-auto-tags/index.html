paperless-enable-auto-tags.py

Schaltet häufig genutzte Tags interaktiv auf matching_algorithm = Automatic um

Was macht das Script?

Sucht in Paperless-ngx alle Tags, die mit mehr als X Dokumenten verknüpft sind (--min-documents X) und deren matching_algorithm noch nicht auf Automatic steht. Für jeden gefundenen Tag wird interaktiv per einzelnem Tastendruck gefragt, ob er umgestellt werden soll.

Hintergrund

Neu per API angelegte Tags (z. B. durch paperless-ai-classify.py) landen in Paperless standardmäßig mit matching_algorithm "Any word", nicht "Automatic". Paperless' eingebauter ML-Klassifikator ("Automatic Matching", periodisch trainiert bzw. manuell per document_create_classifier) berücksichtigt aber nur Tags mit matching_algorithm = Automatic. Dieses Script hilft, gezielt die am häufigsten genutzten Tags (= die meisten Trainingsdaten liefernd) dafür freizuschalten, ohne den gesamten Tag-Bestand blind umzustellen.

Verwendung

AufrufWirkung
./paperless-enable-auto-tags.py --min-documents 5 Fragt interaktiv für jeden Tag mit mehr als 5 verknüpften Dokumenten (und noch nicht Automatic), ob er umgestellt werden soll.
./paperless-enable-auto-tags.py --min-documents 5 --dry-run Fragt weiterhin interaktiv ab, ändert aber nichts in Paperless — zum gefahrlosen Testen des Ablaufs.

--min-documents (bzw. -n) ist Pflicht. Gefundene Tags werden absteigend nach Dokumentenanzahl abgefragt (häufigste zuerst).

Interaktive Bedienung

Bei jedem gefundenen Tag erscheint eine Abfrage inkl. aktuellem matching_algorithm und Dokumentenanzahl:

Tag 'Rechnung' (12 Dokumente, aktuell 'Any word') auf 'Automatic' umstellen? [y/N, Esc=Abbrechen]
y / YTag auf Automatic umstellen.
n / N / EnterTag überspringen, unverändert lassen.
Esc / Strg+CScript sofort abbrechen — bereits vorgenommene Änderungen bleiben bestehen, es wird nichts rückgängig gemacht.

Voraussetzungen

  • Benötigt ein echtes Terminal — die Tastenabfrage funktioniert nicht ohne interaktive Sitzung (Skript bricht ohne TTY mit Fehlermeldung ab).
