ping-servers.sh

Schneller Erreichbarkeits-Check für die opn.ds-Server

Was macht das Script?

Pingt jeden angegebenen Host einmal (Timeout 2 Sekunden) und zeigt pro Zeile an, ob er erreichbar ist — inkl. Antwortzeit bei Erfolg. Ohne Parameter wird eine fest hinterlegte Liste der internen opn.ds-Server geprueft. 

OK   srv1.opn.ds  (0.412 ms)
OK   srv11.opn.ds  (1.038 ms)
FAIL srv99.opn.ds  (nicht erreichbar)

Verwendung

AufrufWirkung
./ping-servers.sh Pingt alle Standard-Server der Domain opn.ds (srv1, srv2, srv3, srv5, srv6, srv7, srv11, srv12, srv13, srv81).
./ping-servers.sh host1 host2 ... Pingt ausschließlich die angegebenen Hosts statt der Standardliste.
